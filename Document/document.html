Selectors

CSS selectors are patterns used to target HTML elements for styling. They are the "who" in any CSS rule.

Every CSS rule starts with a selector followed by a declaration block containing properties and values.

Basic selectors include the type selector, class selector, ID selector, and the universal selector.

The type selector targets elements by tag name. The class selector uses a dot prefix, and the ID selector uses a hash.

Attribute selectors allow you to target elements based on the presence or value of their HTML attributes.

Combinators define the relationship between selectors. There are four: descendant, child, adjacent sibling, and general sibling.

Pseudo-classes target elements based on state or position, such as hover, focus, or nth-child.

Pseudo-elements target virtual parts of an element, such as the first letter or generated content before and after.

p { color: red; } .card { padding: 1rem; } #navbar { position: fixed; }

Specificity determines which rule wins when multiple selectors target the same element. IDs beat classes, classes beat types.

The cascade resolves conflicts using specificity, inheritance, and source order as tiebreakers.

  • [class~="word"] — matches a whole word in a class list
  • [class*="sub"] — matches any substring in the value
  • [class^="start"] — matches values that start with the string
Box Model

Every HTML element is a rectangular box made of four layers: content, padding, border, and margin.

The content area holds the actual text or images. Padding adds space between the content and the border.

The border wraps around the padding. The margin is the outermost layer, separating the element from its neighbours.

By default, width and height only apply to the content area. This is called content-box sizing.

Setting box-sizing to border-box makes width and height include padding and border, which is easier to work with.

Margin collapse occurs when the vertical margins of adjacent elements merge into a single margin equal to the largest value.

Overflow controls what happens when content is larger than its container. Options include visible, hidden, scroll, and auto.

* { box-sizing: border-box; } div { margin: 0 auto; padding: 1rem; }
  • Padding shorthand order: top, right, bottom, left
  • Margin collapse only affects vertical (top/bottom) margins
Flexbox

Flexbox is a one-dimensional layout model that arranges elements along a single axis, either a row or a column.

The flex container is the parent element with display: flex applied. Its direct children become flex items.

The main axis is the primary direction items flow. The cross axis runs perpendicular to it.

justify-content controls spacing and alignment along the main axis. align-items controls alignment on the cross axis.

flex-wrap controls whether items stay on one line or wrap to the next when they exceed the container width.

align-self can be applied to individual flex items to override the container's align-items setting.

The flex shorthand sets flex-grow, flex-shrink, and flex-basis in one declaration.

display: flex; justify-content: space-between; align-items: center;
  • flex-start — aligns items to the start of the axis
  • space-evenly — equal space between and around all items
  • flex-wrap: wrap — allows items to move to new lines
Positioning

CSS positioning controls where elements are placed on the page and how they interact with surrounding elements.

Static is the default. Elements follow normal document flow from top to bottom and left to right.

Relative positions an element relative to its original place. It still occupies its original space in the flow.

Absolute removes an element from the flow. It is positioned relative to its nearest positioned ancestor.

Fixed removes an element from the flow and pins it to the viewport. It stays visible while the page scrolls.

Sticky is a hybrid. The element acts as relative until it hits a scroll threshold, then becomes fixed.

Z-index controls the stacking order of elements. Higher values appear on top. It only works on positioned elements.

Floats move elements left or right, allowing content to wrap around them. Clear prevents overlap with floated elements.

position: absolute; top: 0; left: 0;
  • z-index only works on elements with a position other than static
  • Sticky requires a defined top, bottom, left, or right value
Visual Effects

CSS provides a range of properties to create visual effects without the need for images or JavaScript.

The filter property applies effects like blur, brightness, contrast, grayscale, sepia, and hue-rotate to elements.

The transform property enables 2D and 3D manipulations including translate, scale, rotate, and skew.

Gradients create smooth color transitions. Linear gradients go along a straight line; radial gradients radiate from a point.

The border-radius property rounds the corners of an element. A value of 50% on a square creates a perfect circle.

Box-shadow adds a shadow effect behind an element. It accepts horizontal offset, vertical offset, blur, spread, and color.

The outline property draws a line outside the border without affecting layout. It is commonly used for focus indicators.

filter: blur(4px);
